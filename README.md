# Pathfinder

A single-developer attempt at a space game with a simulated world: fly from
orbit to a planet's surface with no loading screen, build an organisation, and
be pulled back down by the coalitions that forms against you.

`Pathfinder` is the repository's name. The game does not have one yet, and
`Ledger` — which appears throughout the source as `LedgerCore`, `LedgerTerrain`
and so on — is a codename, not a title. See [docs/naming.md](docs/naming.md).

**Roadmap and live progress: https://maximdolphin.github.io/Pathfinder/**

## What this is, honestly

Very early. The terrain, flight model, streaming and materials work; the
settlement is thirty-two generated boxes and the trees are cones. The plan is
about four years of one person's evenings, and
[the roadmap](https://maximdolphin.github.io/Pathfinder/) says so rather than
flattering itself.

Most of the code is written by Claude, working against that roadmap, with the
reasoning for each decision in the commit messages rather than in someone's
memory.

## Layout

```
client/      Unreal 5.8 project. Twelve modules, strict downward dependencies.
src/         The Phase 0 Rust simulation. Frozen, still tested. See src/README.md.
roadmap/     The roadmap data, the generator, and the viewer published above.
tools/       Build-time checks: module layering, capture comparison, asset licences.
docs/        Design, architecture, quality bar, decision records.
surfaces/    Surface manifest. The textures themselves are not in version control.
```

## Building

Unreal Engine 5.8, Windows.

```bash
"%UE_ROOT%\Engine\Build\BatchFiles\Build.bat" LedgerEditor Win64 Development -Project="%CD%\client\Ledger.uproject"
```

The surface textures are re-fetchable from the asset ids in
`surfaces/manifest.json`; `tools/import_surfaces.py` and
`tools/make_import_settings.py` turn them back into engine assets. A clone
without them renders untextured ground and says so rather than failing.

## The checks that run on every commit

```bash
python tools/check_modules.py      # no undeclared or upward module dependency
python tools/check_surfaces.py     # every texture has a source and a licence
python tools/compare_captures.py   # renders match the committed references
cargo test --locked                # the frozen simulation's invariants
```

`tools/compare_captures.py` exists because three rendering regressions survived
review here by being checked with a glance at one convenient image.
